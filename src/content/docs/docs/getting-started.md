Singularity is a Wayland desktop environment built on `labwc`, with its own
shell, a shared application framework, and a small family of first-party apps.
It is designed to be calm by default, quick under your hands, and yours to shape.

This documentation has three parts.

## Using Singularity

If you want to run and live in the desktop, start here:

- [Install](/docs/install/) covers the ways to get Singularity onto a machine.
- [First boot](/docs/first-boot/) walks through the greeter and your first login.
- [Desktop tour](/docs/desktop-tour/) introduces the panel, the dock, and the
  overview, with deeper pages for each piece.

## Building on Singularity

If you want to build apps, plugins, widgets, or themes:

- [Under the Hood](/docs/under-the-hood/) explains how the pieces fit together.
- [Build from source](/docs/build-from-source/) gets the full system compiled.
- [Build an App](/docs/build-an-app/) and [vetro](/docs/vetro/) cover the app
  workflow.

## The bigger picture

[Singularity OS](/docs/singularity-os/) is where the project is heading, and
[Contributing](/docs/contributing/) is how to help get it there.
