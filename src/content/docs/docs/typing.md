## The screen keyboard

On a touch screen the screen keyboard comes up by itself when a text field takes
focus. On a computer, turn it on in **Settings, Accessibility, Typing, Screen
Keyboard**: it then has Ctrl, Alt, Super and Shift keys as well.

- **Swipe typing**: slide a finger across the letters of a word without lifting
  it. A trail follows the finger and the word is typed when you lift.
- **Word completion**: suggestions appear above the keys; tap one to use it.
  Swipe typing and completion know English, Italian, German, French, Spanish and
  Brazilian Portuguese. They follow the first of your spell-check languages, or the
  system language when none is set.
- **Languages**: the keyboard follows the system language and the keyboard
  layouts you added. On a phone the language key switches to the next one.
- **Feedback**: on phones every key press vibrates.

On a TV the keyboard is driven by the remote. See
[Singularity on a TV](/docs/tv/).

## Input methods

Chinese, Japanese, Korean, Vietnamese and other languages need more than a
keyboard layout. Add them in **Settings, Keyboard, Input Methods**:

1. Choose **Add an Input Method** and search for the language or the engine, such
   as Pinyin, Japanese or Hangul.
2. Switch between your input methods and the keyboard layout with **Ctrl+Space**,
   in any text field, or from the top bar when **Show in the Panel** is on.

Candidates appear next to the text cursor. Input methods need the Sinty input
service; the page says so when it is missing.

### Options of an input method

Select an input method in the list to change its options. Which ones appear
depends on the language, for example:

- **Write In**: Simplified or Traditional Chinese, as in Taiwan or Hong Kong;
- **Full-Width Punctuation**: type `，。？` instead of `, . ?`.

### Learned phrases

With **Learn From What You Type** on, new phrases and the candidates you pick
often come first. What is learned stays on this computer.

- **Learned Phrases** lists them; you can remove one or add your own with
  **Add a Phrase**.
- **Export…** and **Import…** move them to another computer.
- **Forget Everything** removes every learned phrase and frequency.

### Your own table

**Import a Table** adds Wubi, Cangjie or any table you made, also tables from
Rime and fcitx, as a new input method. Only tables you made, or whose license
allows copying, can be imported.

## One-time codes

Codes you receive by message or mail are offered when you fill in a code field,
in the suggestion bar of the screen keyboard and from the input method. They
stay in memory for ten minutes and never reach the clipboard or its history.

Choose where codes come from in **Settings, Privacy, One-Time Codes**:

- **Messages**: text messages on this computer;
- **Mail**: codes in Lettere;
- **Phone**: messages from your phone through Nearby;
- **Other Apps**: apps that declare they send codes.

**Delete After Use** removes the message once its code has been used. A code can
also be held from its notification, ready to paste.
