The desktop runs today. The operating system does not yet, and this page is a
signpost rather than a release.

Singularity OS is the longer arm of the project: a system built around the
desktop rather than the other way around. The plan is for it to be immutable,
with a base that is reproducible and verifiable instead of one that drifts as you
use it.

## Atom Loops

The idea that keeps the system fresh is [Atom Loops](/docs/atom-loops/). Rather
than mutating the system in place, each update lands as a clean, known state, so
the machine you boot tomorrow is as predictable as the one you booted today.

## Status

None of this ships yet. The OS is coming soon. For now, the thing you can run is
the desktop, and that is where the work is. Follow the [news](/news/) for what
lands as it lands.
