---
title: Markup
description: Annotate screenshots and images.
---

Markup annotates screenshots and images. A screenshot opens in Markup from the
**Markup** button in its notification.

## Tools

| Tool | Key |
|---|---|
| Select and Move | V |
| Pen | P |
| Highlighter | H |
| Arrow | A |
| Rectangle | R |
| Ellipse | O |
| Text | T |
| Numbered Step | N |
| Redact | B |
| Crop | C |

**Redact** hides what must not be seen, by blurring or pixelating it.
Pick the color and the thickness for each tool. **Live Text** lets you select the
text inside the image and copy it.

## Saving

Copy the result with Ctrl+C, share it, save it over the original or as a new
image, or open it in Draw to keep working on it. Undo and redo work as everywhere
else.
