---
title: Draw
description: Draw diagrams, flowcharts and vector graphics.
---

Draw makes diagrams: flowcharts, org charts, UML, BPMN, network and floor plans,
electrical and process diagrams, interface mockups and more, from libraries of shapes.

- Connectors that follow the shapes, layers, guides and comments.
- **Shape data**: fields on each shape, linked to a spreadsheet, a CSV file or a
  database, and org charts built from a CSV file.
- Stencils and favorites for the shapes you use.

Drawings open from OpenDocument, Visio, draw.io, SVG and OpenRaster files, and
export as ODG, SVG, Visio and PowerPoint.
