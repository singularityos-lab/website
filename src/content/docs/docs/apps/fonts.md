---
title: Fonts
description: Browse, preview and install fonts.
---

Fonts shows the fonts on the computer and installs new ones.

- Browse by collection: sans serif, serif, monospace, display and handwriting, or
  the fonts you installed.
- Type in the preview to see your own text in every font, and open a font to see
  all its styles.
- **Install Font** adds a `.ttf`, `.otf` or `.woff` file. You can also drop a font
  file on the window, or open one from Files.

Fonts you install are only for your account. Fonts installed for everyone are
shown too, but only the ones you installed can be removed.
