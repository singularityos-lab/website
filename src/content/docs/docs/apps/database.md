title: Database
description: Build databases with tables, queries, forms and reports.
---

Database builds and uses databases with tables, queries, forms and reports.

- **Tables** with fields, indexes and relationships.
- **Queries** built by picking tables and fields, or written in SQL, with joins,
  filters and sorting.
- **Forms** to enter and browse records, with subforms for related records, and
  **reports** to print or export as PDF, Excel, HTML or text.
- **Actions** that run when records change.

A database is a SQLite file, or a connection to a PostgreSQL, MySQL or MariaDB
server, where you can also manage accounts and roles. Access databases are
converted when you open them, and a database can be created from CSV, Excel, JSON
or SQL files.
