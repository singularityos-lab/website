---
title: Translate
description: Translate text and files between languages, and keep a phrasebook.
---

Translate translates text as you type.

- Pick the languages, or let Translate detect the source. **Swap Languages**
  turns the translation around.
- **Translate Clipboard** translates what you copied, and **Translate File**
  translates a text or Markdown file in one go.
- **Listen** reads the translation aloud.
- Star a translation with Ctrl+D to keep it in the **phrasebook**, which you can
  search and export as CSV. Recent translations are kept in the history, which
  can be turned off.

## Services

Choose the service in Settings, Apps, Translate:

- **LibreTranslate**, the default, on `libretranslate.com` or an instance of your
  own. Some instances need an API key, kept in the keyring.
- **Lingva**, on an instance of your choice.
- **MyMemory**, which is also used for short texts when the chosen service is down
  or busy, unless you turn that off.

The text you translate is sent to the service you choose.
