---
title: Machines
description: Run other operating systems in virtual machines.
---

Machines runs other operating systems in virtual machines, with hardware
acceleration (KVM) when the computer supports it.

- **New Machine** installs a system from an ISO image, or imports a disk image.
  The system is recognized from the image's file name or disc label, and Machines
  picks fitting settings.
- Set the processors, memory and disk size, the firmware and folders shared with
  the machine.
- Start, pause, restart and turn off a machine, and work with it in a window or
  full screen.
- **Snapshots** keep the disk and running state, and restore them later.
