title: QR Codes
description: Scan and create QR codes and barcodes.
---

QR Codes reads codes and makes new ones.

## Scanning

- Point the **camera** at a QR code or a barcode.
- Read the codes in a **picture** or a **screenshot**, or in an image you copied.
- Read every code in many pictures at once and export the list as CSV.

The result shows exactly what the code holds and offers what fits: open a link,
join a Wi-Fi network, add a contact to Contacts, add a two-factor code to
Authenticator, or look up a book by its ISBN.

## Creating

**Create a Code** makes a QR code for a link or text, a Wi-Fi network, a contact or
a location, and barcodes for products (EAN-13, EAN-8, UPC-A) and labels (Code
128). A contact can be filled in from Contacts, and the current Wi-Fi network
from the saved networks, so guests can scan it to join.

Higher error correction keeps a code readable when it is partly damaged, but
makes it denser. Save codes as PNG or SVG, or copy them as an image.

Codes you scan or create are kept in the **History**.
